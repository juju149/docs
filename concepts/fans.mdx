# Fans

**Fans** are subscribers who interact with your content. Elys tracks their engagement, spending, and provides AI-powered insights.

## Fan Structure

```json
{
  "id": "fan_123",
  "username": "mike_loves_luna",
  "totalSpent": 250.00,
  "isSubscribed": true,
  "aiScore": 85,
  
  // Enhanced Psychology (New)
  "psychProfile": {
    "attachmentStyle": "anxious", 
    "personality": "extrovert"
  },
  "communicationStyle": "flirty", // formal, casual, flirty
  "emotionalState": "lonely",     // detected from recent messages
  
  // Relationship Tracking
  "relationshipStage": "intimate", // stranger -> acquaintance -> friend -> intimate
  "purchaseTriggers": ["loneliness", "exclusive_content"]
}
```

## Fan Psychology & Insights

Elys automatically analyzes fan messages to extract:

- **Psychological Profile**: Attachment style and personality traits
- **Emotional State**: Real-time mood detection (happy, lonely, horny, etc.)
- **Purchase Triggers**: What motivates them to spend
- **Personal Info**: Extracted facts (job, location, pets) stored in memory

## AI Score

The **AI Score** (0-100) indicates fan engagement potential:

| Score | Label | Description |
|-------|-------|-------------|
| 0-30 | Cold 🥶 | Low engagement, unlikely to purchase |
| 31-50 | Warm 🌡️ | Moderate interest, needs nurturing |
| 51-70 | Hot 🔥 | High engagement, ready to buy |
| 71-90 | Whale 🐋 | Top spender, VIP treatment |
| 91-100 | Superfan 💎 | Maximum value, exclusive content |

## Platforms

Elys supports fans from:

- **FANSLY** - Fansly followers  
- **MYM** - MYM subscribers
