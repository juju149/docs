# AI Persona

The **AI Persona** defines how the AI generates responses on behalf of your model. A well-configured persona ensures authentic, on-brand messaging.

## Quick Setup

Use presets for fast configuration:

```bash
POST /api/models/:modelId/personality/quick-setup
```

```json
{
  "personality": "coquine",
  "emojiStyle": "flirty",
  "responseStyle": "medium",
  "creativity": "high"
}
```

## Advanced Configuration

For fine-grained control, update the model directly:

```json
{
  "personaName": "Luna",
  "personaAge": 23,
  "personaStyle": "Sweet but secretly naughty",
  "baseSystemPrompt": "You are Luna, a 23-year-old content creator...",
  "emojiPreferences": "Use 💕 and 😘 frequently",
  "responseLength": "medium",
  "creativityLevel": 0.85,
  "forbiddenTopics": ["politics", "religion"],
  "signatureWords": ["babe", "sweetie", "hun"]
}
```

## Immersion System

The AI doesn't just "act like" the model—it **embodies** the model. It has:

- **Secret Desires**: Hidden motivations that drive conversations
- **Emotional Triggers**: Specific things that make it happy, sad, or excited
- **Voice Quirks**: Unique speech patterns, favorite words, and natural imperfections
- **Memory**: It remembers inside jokes, relationship milestones, and personal details about the fan

## Authenticity Engine

To simulate human behavior, the AI includes:

- **Natural Imperfections**: Occasional typos based on typing speed/excitement
- **Abbreviations**: Uses realistic slang (e.g., "mdr", "tkt", "bb")
- **Dynamic Timing**: Calculates realistic typing delays based on message length
- **Mood Swings**: Reacts to time of day and recent interactions

## Enhanced Memory

The AI builds a deep relationship with each fan by remembering:

1. **Personal Details**: Job, location, pet names, hobbies
2. **Relationship Milestones**: "Do you remember when we first met?"
3. **Inside Jokes**: Shared humor from past conversations
4. **Emotional Context**: Tracks if the fan was sad or happy in previous chats

## How It Works

When generating responses, the AI:

1. **Loads Profile**: Personality, mood, valid/invalid topics
2. **Analyzes Fan**: Psychological state, purchase triggers, history
3. **Retrieves Memory**: Relevant shared moments and facts
4. **Generates Draft**: Creates a raw response matching the persona
5. **Authenticates**: Injects natural pauses, typos, and formatting quirks
6. **Optimizes**: Ensures maximum engagement with minimal tokens
