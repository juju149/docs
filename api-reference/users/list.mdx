---
title: List Users
api: GET /api/users
description: List all users (Manager only)
---

<Note>Requires **MANAGER** role</Note>

<ParamField query="page" type="integer" default="1">Page number</ParamField>
<ParamField query="limit" type="integer" default="20">Items per page</ParamField>
<ParamField query="role" type="string">Filter by role (MANAGER or MODEL)</ParamField>

<ResponseExample>
```json
{
  "data": [
    { "id": "user_123", "email": "manager@example.com", "role": "MANAGER" }
  ],
  "pagination": { "page": 1, "limit": 20, "total": 5 }
}
```
</ResponseExample>
