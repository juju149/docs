# Audit Logs

Access audit logs for tracking system activity. **Manager only.**

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/audit` | List audit logs |
| GET | `/api/audit/stats` | Get audit stats |
| GET | `/api/audit/{logId}` | Get log details |
| GET | `/api/audit/entity/{entity}/{entityId}` | Logs by entity |
