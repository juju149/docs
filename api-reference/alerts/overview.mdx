# Alerts

System notifications and alerts for important events.

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/alerts` | List alerts |
| GET | `/api/alerts/unread-count` | Get unread count |
| POST | `/api/alerts/mark-all-read` | Mark all as read |
| GET | `/api/alerts/{alertId}` | Get alert |
| PATCH | `/api/alerts/{alertId}` | Update alert |
| DELETE | `/api/alerts/{alertId}` | Delete alert |
